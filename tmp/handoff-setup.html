CCFD1 Dashboard: Setup

About 15 minutes. Do these in order.

Accounts

  1. Get a GitHub account: go to github.com/signup and complete with your email. Send me your username so I can add you to the project.
  2. Get an Anthropic API key: go to console.anthropic.com and sign up. Open Billing and add $5 of credit. Open API Keys, click Create Key, and copy it (starts with sk-ant-).

Option A: Run on your own computer (Mac or Windows)

  1. Install Docker: go to docker.com/products/docker-desktop, download, install, and open it.
  2. Install Git: Mac: open Terminal and run xcode-select --install. Windows: go to git-scm.com and install, then use Git Bash for the next step.
  3. Download and start it (paste your API key when asked): 
    git clone https://github.com/ashutosh13/CCFD1-Decision-Intelligence.git ~/ccfd1 && cd ~/ccfd1 && ./start.sh
  4. Open it: go to http://localhost:8000

Option B: Run on a server (Linux, Ubuntu)

  1. Install Docker and Git: 
    curl -fsSL https://get.docker.com | sh && sudo apt-get install -y git
  2. Download and start it (paste your API key when asked): 
    git clone https://github.com/ashutosh13/CCFD1-Decision-Intelligence.git ~/ccfd1 && cd ~/ccfd1 && sudo ./start.sh
  3. Open it: go to http://YOUR-SERVER-IP:8000

Day to day

cd ~/ccfd1 && git pull && ./start.sh     # get the latest and restart
cd ~/ccfd1 && ./stop.sh                  # stop it

Use sudo in front of these on a server. To use a different port, run PORT=9000 ./start.sh.
