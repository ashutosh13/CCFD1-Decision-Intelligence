CCFD1 Dashboard: Handoff

Setup takes about 15 minutes. This handoff runs the dashboard using the already ingested data. For future updates see the 'Updating Data' Section below.

1. Accounts needed

AccountSign upWhat to do
GitHubgithub.com/signupAfter creation, send your username to the group to be added to be authorized for the project.
Anthropic API key (for the assistant)console.anthropic.comOpen Billing and add $5. Open API Keys, click Create Key, copy it (starts with sk-ant-).

No key? You can skip it. The dashboard works, only the assistant is off.

2. Installing Dependencies

ComputerInstall this
MacDocker Desktop (docker.com/products/docker-desktop), then in Terminal run xcode-select --install for Git.
WindowsDocker Desktop (docker.com/products/docker-desktop), then Git from https://git-scm.com/install/windows. Use Git Bash for every command below.
Linux servercurl -fsSL https://get.docker.com | sh && sudo apt-get install -y git

Open Docker Desktop once so it is running before you continue.

3. Running code

  1. Paste this (it downloads the project, then starts it): 
    git clone https://github.com/ashutosh13/CCFD1-Decision-Intelligence.git ~/ccfd1 && cd ~/ccfd1 && ./start.sh
  2. The script checks for your Anthropic API key (from Step 1). If it is missing or not accepted, it asks you to paste a valid one. Press Enter to skip the assistant.
  3. Open http://localhost:8000 (on a server: http://YOUR-SERVER-IP:8000).

On a server put sudo in front of ./start.sh. For another port: PORT=9000 ./start.sh.

Day to day

cd ~/ccfd1 && ./start.sh   # get the latest and restart
cd ~/ccfd1 && ./stop.sh   # stop it

If something goes wrong

You seeDo this
Cannot connect to the Docker daemonOpen Docker Desktop and wait until it says it is running.
Assistant does not answer or page does not appearThe API key is missing or wrong. Run ./start.sh again and paste a valid key when asked.
git clone or git pull failsSign in to GitHub, or ask team to check access.

Next steps: Updating Data and project Matinence post-deployment

Next steps. Everything above gets the dashboard running with the data already loaded. Do this part later, when new Daily Blotter PDFs arrive. Updating data is a different job from running the dashboard, and it needs extra tools and accounts.

One-time setup for updating

  1. Install Python 3.10+, Node.js 20+ and Git (Git is already installed from step 2).
  2. Sign in to GitHub so git push works. Your username must have write access (see Accounts needed).
  3. In the GitHub repo, open Settings > Pages and set Source to GitHub Actions.
  4. From ~/ccfd1 run python3 run.py --setup. It asks for your Anthropic API key, a Cloudflare API token (permissions: Workers Scripts Edit and Workers KV Storage Edit) and your Cloudflare account ID. They are saved in .env and never committed.
    Mac: after running --setup once in Terminal, you can double-click run.command. Windows: use run.bat --setup.
